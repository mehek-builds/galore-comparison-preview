# Local Galore homepage iteration

Open `preview.html` for the standalone local review. It was built from the current trygalore.com homepage as served on November 25, 2026. `index.html` and the local CSS/JS files are editable source; `build_preview.py` rebuilds the standalone file. Nothing in this folder is connected to GitHub or deployed.

The existing hero, device mockups, market tape, feature grid, FAQ layout, and brand colors remain. Seven focused improvements are visible:

1. The hero offers one clickable belief: “Data centers will run on nuclear.”
2. The existing Dashboard tabs now change the content inside the same laptop and phone mockups.
3. Explore shows possible CEG and VST connections, evidence slots, and a risk. These are illustrative, without invented source citations.
4. The existing sample belief result, after the simulated gate, shows a same-period SPY sample comparison with data and fee limitations.
5. Portfolio shows a sample paper order amount, remaining cash, a slider, and a separate review action. No order is placed.
6. Watchlist shows how a hypothetical update relates to the saved belief and what evidence would need to be checked.
7. The homepage FAQ now surfaces existing pricing, explains the paper-only demo, and says where dated evidence would appear.

The local signup is simulated: no name or email is sent or saved. The browser keeps a small demo access flag so the gated sample result can be viewed during review. To see the first-time gate again, clear site data for the local file or use a private window.

The standalone page loads images and the Geist font from the current public site because they are not bundled here. The local server cannot bind in this environment, so browser-based visual and click-through QA were unavailable. JavaScript syntax and HTML structure were checked locally. No production behavior is certified by the demo.
