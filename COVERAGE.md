# Galore 100-friction design coverage

This is a design walkthrough of the 100 friction points raised on November 23. The original list was recovered from the conversation in groups; short issue descriptions below are paraphrases. “Covered” means the preview visibly resolves the communication or interaction problem, sometimes by showing an explicitly illustrative state. It does not certify production functionality, actual prices, source retrieval, account creation, brokerage execution, or pricing.

## Verification boundary

The comparison site can illustrate all 100 communication and interface resolutions above. It does not connect to Galore's real account, research, market-data, or brokerage systems. Specific source links, genuine backtests, live holdings, a true waitlist write, and authentication can only be verified in the production app. The dashboard preview keeps sample choices in session storage; the website waitlist interaction does not send or save personal data. The pages use no fictitious public-person performance figures.
