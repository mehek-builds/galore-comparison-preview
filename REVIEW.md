# Galore design walkthrough review

The prototype covers the 100 interface and communication issues listed in `COVERAGE.md` through open examples and explicit simulated states. It is a standalone preview; the real Galore website and dashboard remain separate.

The public site now keeps the waitlist as its primary action, exposes a concrete belief in the hero, and links to an interactive dashboard. The site uses example story tabs, visible source and risk requirements, clear paper/live distinctions, direct About and Pricing links, a smaller illustrative ticker strip, and a preview-only form. Unverified named trade badges and fictional news attribution were removed.

The dashboard preview has five primary destinations. Home opens a sample research flow; Explore shows three ideas; the research view explains possible connections, evidence, risks, and a fictional comparison layout with period controls; Watchlist saves example beliefs; Portfolio allows a reviewed simulated order against $10,000 of paper cash; People separates creators, politicians and investors; More explains account access, brokerage status, AI connections, rules, and deletion. A weekly leaderboard shows an honest empty state. All sample selections are held in session storage and can be cleared. Nothing sends an email, writes to the real waitlist, fetches live sources, or executes a trade.

Static verification completed: changed JavaScript passed `node --check`; the dashboard includes all eight walkthrough views; IDs are unique; the 100-row coverage map is sequential. A local HTTP server could not bind in this environment (`PermissionError: Operation not permitted`), and the connected browser control could not initialize (`Managed execution requires a usable CODEX_CLI_PATH`). No visual or click-through browser test has passed in this environment. The comparison site remains a design preview and no production app behavior is certified.
