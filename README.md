# Galore design preview

This is a separate review site. It does not alter trygalore.com or the Galore app. The website waitlist interaction is simulated and sends nothing. The interactive dashboard walkthrough shows fictional research shapes, example source requirements, a saved watchlist, and sample paper orders stored only in the browser session. It does not show actual performance or place trades. Contact points to the current live contact page.

Open `/dashboard-preview.html` to explore Home, Explore, research, Watchlist, Portfolio, people, leaderboard, account access, brokerage, and AI connection states. The flow includes example belief entry, invalid-input feedback, practice-order review, and an invited-member sign-in illustration. `COVERAGE.md` maps the 100 presentation observations from Astor, Conviction, Volaren, and Mochatrade to shown, adapted, or held treatments. The earlier coverage file mistakenly mapped a separate list of Galore friction points.

## Comparison ideas implemented

1. The hero says what to do in ordinary language and gives one primary action.
2. A single belief carries through the explanation instead of changing examples at every step.
3. The example plays through five timed scenes: idea, connections, evidence, practice order, and watch. Visitors can pause, replay, or select a scene.
4. Each connection gets a short causal explanation.
5. Risks and historical comparison appear before any portfolio action.
6. The dashboard preview lets visitors explore Home, Explore, Portfolio, and Watchlist without invented returns.
7. The six feature modules use question headings and short leads that answer a visitor's next question.
8. The page uses open sections, borders, and spacing instead of a grid of decorative cards.
9. The site uses #000412, #E8EEF2, and #2BF08A for the main canvas, text, and attention.
10. Mobile navigation, a persistent waitlist action, keyboard tabs, reduced motion, and readable disclosure controls carry the same story to a small screen.

Motion in this build includes the slow background water, continuous market tape, a timed product walkthrough with typing, branching connections, evidence trace, order review and saved-belief update, plus feature demonstrations, menu, waitlist sheet, FAQ disclosure, and press feedback. Reduced-motion settings switch the walkthrough to manual scene selection. The review site uses `noindex, nofollow`.
